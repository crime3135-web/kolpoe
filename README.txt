Crystal Deals — сайт + сервер (без внешних зависимостей, нужен Node.js 18 или новее)

ЗАПУСК
  ADMIN_PASSWORD=ваш_пароль node server.js
  Сайт: http://localhost:3000     Менеджер: http://localhost:3000/admin.html

ПЕРЕМЕННЫЕ
  PORT              порт (по умолчанию 3000)
  ADMIN_PASSWORD    пароль менеджера (без него админка выключена)
  TON_WALLET        адрес для пополнений TON (по умолчанию ваш)
  TONCENTER_KEY     ключ toncenter.com (бесплатный, снимает лимиты запросов)
  TEST_BALANCE      сколько RUB дарить новым аккаунтам (для тестов, например 10000; для боя не задавайте)
  DATA_FILE         путь к файлу данных (по умолчанию data.json рядом с server.js)

ЧТО УМЕЕТ СЕРВЕР
  Регистрация и вход (пароли хешируются scrypt), сделки по ссылке между разными устройствами,
  чат с фото, оплата с баланса, передача товара со скриншотом, подтверждение, вывод заявкой,
  обменник, пополнение TON (сервер сам раз в 30 секунд ищет платёж по комментарию и сумме,
  каждая транзакция засчитывается один раз), админка менеджера (выводы, споры, ручное пополнение).

ПЕРЕД БОЕВЫМ ЗАПУСКОМ
  1. Поставьте за HTTPS (Caddy или nginx + Let's Encrypt). Запускайте через pm2 или systemd.
  2. Данные лежат в data.json: делайте резервные копии. Для большой нагрузки перенесите в PostgreSQL.
  3. Курсы валют в server.js (константа R) демонстрационные. Подключите живой источник.
  4. Проверка TON идёт через публичный toncenter. Для надёжности используйте ключ TONCENTER_KEY.
  5. Хранение чужих денег может требовать лицензий и правил (KYC/AML) в вашей юрисдикции. Проверьте это.
